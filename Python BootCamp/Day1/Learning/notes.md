## Strings

Em python uma string pode ser representado pelo tipo `str`; É uma sequência de caracteres usada para armazenar dados textuais, como palavras, frases, e-mails ou números em formato de texto.

**Como criar uma string**

Use aspas Simples: `'olá mundo`
Use aspas Duplas: `"olá mundo"`

## Inputs

A função input() em Python é o comando nativo utilizado para receber dados enviados pelo usuário através do teclado.


**O texto dentro dos parênteses é a mensagem que aparece na tela**

```python
nome = input("Digite o seu nome: ")
print(f"Olá, {nome}! Seja bem-vindo.")
```

## Variáveis

Em Python, variáveis são espaços na memória usados para guardar dados. Elas são criadas usando o sinal de igual `=` como operador de atribuição, sem precisar declarar o tipo antes. O Python define o tipo de dado automaticamente com base no valor que você fornece.
