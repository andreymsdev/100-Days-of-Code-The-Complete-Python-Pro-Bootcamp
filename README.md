# 100 Days of Code - Python Pro Bootcamp

This repository contains my code and notes for Dr. Angela Yu's **100 Days of Code: The Complete Python Pro Bootcamp** course on Udemy.

## Goal
The main focus of this repository is **my personal learning journey**. Since it serves as a study log, you’ll find code, experiments, and daily notes (sometimes a bit messy, but documented as I go).

The ultimate goal is to build 1 project a day for 100 days to master Python — covering automation, data science, web development, and game creation.

## What I'm practicing
- Python 3
- Logic & Data Structures
- Automation & Web Scraping
- Data Science (Pandas, NumPy, Matplotlib)
- Web Development (Flask, APIs, SQL)
