# 100 Days of Code - Python Pro Bootcamp

Este repositório contém meus códigos e anotações do curso **100 Days of Code: The Complete Python Pro Bootcamp** da Dra. Angela Yu (Udemy).

## Objetivo
O foco principal deste repositório é o **meu aprendizado prático**. Por ser um espaço de estudo contínuo, você vai encontrar códigos, testes e anotações do dia a dia (às vezes meio bagunçadas, mas registradas à medida que aprendo).

A meta é construir 1 projeto por dia durante 100 dias para dominar Python — passando por automação, ciência de dados, desenvolvimento web e criação de jogos.

## O que estou praticando
- Python 3
- Lógica de Programação e Estruturas de Dados
- Automação e Web Scraping
- Ciência de Dados (Pandas, NumPy, Matplotlib)
- Desenvolvimento Web (Flask, APIs, SQL)
